# Netflix Data Visualization — CodeAlpha Task 3

## 📌 Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective is to transform the Netflix titles dataset into meaningful visualizations 
and a professional dashboard using Python.

## 🛠 Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Dataset

The dataset contains 8,807 Netflix titles and 12 attributes including:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Description

## 📈 Analysis Performed

- KPI Analysis
- Movies vs TV Shows
- Content Growth
- Country Analysis
- Genre Analysis
- Rating Distribution
- Duration Analysis
- Director Analysis
- Actor Analysis
- Monthly Content Addition
- Country × Content Type Heatmap
- Netflix Dashboard

## 🔍 Key Findings

- Total titles: 8,807
- Movies: 6,131
- TV Shows: 2,676
- Average movie duration: 99.58 minutes
- Average TV Show seasons: 1.76
- TV-MA is the most common rating
- International Movies, Dramas, and Comedies are among the leading categories
- United States has the largest content contribution among analyzed countries

## 📌 Conclusion

The project demonstrates how Python-based data visualization can transform raw 
entertainment data into actionable insights and an effective data story.
